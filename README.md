# Clipping Path Studio Website

Static multi-page website for Clipping Path Studio.

## Publish
Upload the contents of this folder to a GitHub repository and enable GitHub Pages.

## Before publishing
1. Replace all `YOUR BEFORE IMAGE / REPLACE HERE` and `YOUR AFTER IMAGE / REPLACE HERE` placeholders with your authorized portfolio images.
2. Review pricing and turnaround claims against your actual capacity.
3. Test every contact link.
4. Add your final live URL to `sitemap.xml` if you want one.
